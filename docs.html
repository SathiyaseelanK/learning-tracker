🌱 Daily Learning Habit Tracker

A personal learning and habit system built for Sathiyaseelan K — designed to make daily learning as natural as brushing your teeth. Everything lives in a single HTML file with no dependencies, syncing to Google Sheets automatically.

The philosophy: show up every day, even for 30 minutes. Consistency beats intensity. This tracker makes showing up feel rewarding.

📁 File Structure

Three files in your GitHub repository:

├── index.html     ← Main tracker (Today, Plans, Books, Quotes, Dashboard)
├── habits.html    ← Dedicated habit tracker (separate page)

Why two separate files?

The habits tracker is a distinct use case — it's about daily life habits (exercise, sleep, water), while the main tracker is about deep learning (GCP, books). Keeping them separate means:

BenefitDetail
Faster loadEach file loads only what it needs — no bloat
Cleaner focusOpen habits.html for daily check-in, index.html for learning
Independent updatesUpdate one without touching the other
Shared dataBoth use the same Google Sheet — data is shared automatically

Schedule logic

Sessions are assigned to weekdays (Mon–Fri) starting 25 Sep 2026. The schedule updates automatically when you:

ActionEffect on schedule
Complete a sessionNext session moves to the next weekday
Complete multiple in one dayFollowing sessions pull forward — saves future days
Skip a sessionMoves to the end of the plan — doesn't break the chain
Miss a daySession shows as "today" the next time you open — no sessions are lost

Custom plan builder

In the Plans tab, tap 🛠️ Custom Plan. Enter a name, icon, description, color and sessions (one per line). The plan is added to your schedule after all existing plans complete.

Session bookmarks

Inside any session's step-by-step guide, tap ☆ next to any step to bookmark it. Access all bookmarks from Plans → 🔖 Bookmarks. Tapping a bookmark takes you directly back to that step.

🧊 Streak Freeze

Protect your learning streak on days when life gets in the way — a work crisis, travel, illness. Use a freeze token and your streak stays intact.

How to earn freezes

You earn 1 freeze token for every 5 sessions completed. The counter is automatic — no action needed. Tap 🧊 Freeze in the Today tools row to see your current count and when you earn the next one.

Using a freeze

1
Tap 🧊 Freeze in Today tools row
Opens the Streak Freeze info modal showing your current freeze count.
2
Tap "Use Freeze Today"
Consumes 1 freeze token and marks today as protected. You can only use 1 per day.
ScenarioFreeze behaviour
Used today alreadyShows "already used" — can't use again same day
No freezes leftButton is disabled — complete 5 more sessions to earn one
Streak = 0Freeze won't restore a broken streak — only prevents breaking it

❓ FAQ

My streak broke even though I studied — what happened?

The streak counts days where at least one session was marked complete (not just skipped). If you only skipped sessions that day, the streak won't count it. If you genuinely studied, mark the session as Done and it will backfill.

Can I access this on my iPhone?

Yes. Open the GitHub Pages URL in Safari → tap Share → Add to Home Screen. It opens full-screen like a native app.

I lost my streak — can I get it back?

If you completed a session but forgot to mark it, open the Plans tab, find the session, tap it, and mark it Done. The streak recalculates from the actual completion dates.

Can two people use the same tracker?

No — it's designed for one user. The Google Sheet is tied to your email and token. To share progress, use the LinkedIn share feature or copy the Weekly Summary.

My session notes disappeared

Notes auto-save every 2 seconds while you type, but only if the session has already been marked Done or Skipped. If the session is still Pending, notes are saved as a local draft. Complete the session first, then the notes are permanently saved to Google Sheets.

The quotes aren't loading

Quotable.io may be temporarily down. The tracker falls back silently to locally cached or built-in quotes. Try tapping 🔀 New quote — if it loads, the API is back up.

How do I add the Azure plan?

In the Plans tab, tap + Add Plan and select Microsoft Azure. It will be scheduled to start the day after your last GCP session completes.

Can I edit a session I already marked?

Yes. Open the session in the Plans tab and tap ↩ Undo to reset it to Pending, then re-mark with the correct status.

The page loads slowly on first open

The first load fetches your data from Google Sheets (1–2 seconds on WiFi, 3–4 seconds on mobile data). Subsequent loads in the same session are instant. If it's consistently slow, check your internet connection.

My habits data disappeared

Habits are stored in localStorage (per device) and synced to Google Sheets. If localStorage was cleared (e.g. browser reset), the app reloads from Google Sheets on next login — data is safe.
